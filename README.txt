ANNA KUZNETSOVA — PERSONAL PORTFOLIO
====================================

Files:
- index.html: main bilingual website
- styles.css: responsive dark editorial styling
- script.js: RU/EN language switch
- assets/: downloadable CV PDFs (if provided)

Preview:
Open index.html in a browser.

Free publishing:
1. Create a free account at GitHub.
2. Create a public repository named: YOUR-USERNAME.github.io
3. Upload all files and the assets folder to the repository root.
4. In repository Settings -> Pages, enable deployment from the main branch / root.
5. GitHub Pages will publish the site at https://YOUR-USERNAME.github.io

Before publishing:
- Review contact details and CV attachments.
- Add a professional photo or LinkedIn URL if desired.
- Confirm all case-study wording is safe to share publicly.
